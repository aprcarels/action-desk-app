# Integration Strategy

## Product Position
Action Desk is the operational intelligence layer ABOVE existing systems.

## Systems of Record
Action Desk integrates with:
- ERP systems
- WMS systems
- CRM systems
- Carrier systems

## Systems of Communication
Action Desk augments:
- Outlook
- Teams
- Slack
- Email

## Integration Principles
- API-first
- Adapter-based architecture
- Webhook support
- Event-driven processing

## Connector Priorities
### Phase 1
- Outlook/Microsoft Graph
- Teams
- Generic REST API
- Webhooks

### Phase 2
- ERP adapters
- WMS adapters
- Carrier integrations

## Key Rule
Action Desk coordinates operational intelligence.
It does not replace core systems.
