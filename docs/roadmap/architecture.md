# Action Desk Architecture

## Core Principle
Deterministic systems establish operational truth.
AI interprets and explains operational meaning.

## High-Level Components
- Electron Internal App
- React Customer Portal
- Node/TypeScript Backend
- Python Deterministic Engine
- MariaDB
- Integration Layer
- AI Service Layer

## Core Services
### Workflow Engine
Handles deterministic workflow orchestration.

### AI Narrative Layer
Provides:
- summaries
- recommendations
- communication drafting

### Integration Layer
Adapters/connectors for:
- ERP
- WMS
- CRM
- Outlook
- Teams

### Reporting Engine
Operational KPIs and executive analytics.

## Operational Object Model
Core entities:
- Customer
- Shipment
- Workflow
- SLA Event
- Escalation
- Notification
- Issue
