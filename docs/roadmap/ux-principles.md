# UX Principles

## Product Goal
Reduce cognitive load while improving operational clarity.

## UX Philosophy
- Calm interfaces
- Exception-driven visibility
- Minimal noise
- High signal
- Operational storytelling

## Key UX Rules
### Show Only What Matters
Prioritize:
- Risks
- Delays
- Escalations
- Blockers

### AI Summaries Everywhere
Every operational object should explain:
- What happened
- Why it matters
- Customer impact
- Recommended next action

### Progressive Disclosure
Show:
1. Summary
2. Impact
3. Suggested Action
4. Expandable details

### Operational Timelines
Use timelines to explain operational narratives visually.

## Avoid
- Dashboard clutter
- Giant tables
- Raw logs
- Excessive filtering
- ERP-style overload
